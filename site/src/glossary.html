Glossary & sources

Glossary

TermMeaning
ADPCMAdaptive differential PCM: Yamaha's 4-bit sample compression, a quarter the size of 16-bit PCM.
AICAThe Dreamcast's Yamaha sound chip: ARM7DI CPU, 64-channel sample player, DSP, mixer, timers, interrupt controller, MIDI UART and RTC, around 2 MB of sound RAM.
ARM7DIThe AICA's CPU: an ARMv3 core without Thumb or halfword instructions. Runs the sound driver.
Bank tableA table in sound RAM where the SH-4 records the address and size of each downloaded bank.
Channel / slotOne of the AICA's 64 sample-playback voices.
Command (host command)A 16-byte request from the SH-4 library to the driver, delivered in batches of up to 32 through the mailbox.
Direct sendA voice's dry output to the mixer, with its own level and pan.
DSPThe AICA's effect processor: a 128-step program per sample with delay memory in sound RAM.
Effect sendA voice's wet output into one of 16 DSP input buses, with a send level.
Envelope (EG)The hardware amplitude contour: attack, decay 1, decay level, decay 2, release.
Event ringManatee's 1024-entry queue of MIDI-style events: the single path from sequencer, game and MIDI input into the voice engine.
FIQARM "fast interrupt", with its own banked registers. The only interrupt the AICA raises on the ARM.
Filter envelopeA second envelope (five levels, four rates) controlling each voice's low-pass cutoff.
G2 busThe Dreamcast's slow peripheral bus through which the SH-4 reaches the AICA.
GD-DACD audio from the GD-ROM drive, fed into the AICA's external inputs.
HollyThe Dreamcast's system ASIC (graphics, bus bridges, DMA, interrupt routing).
Key on / key offStarting a voice (sample and envelopes restart) / moving it into its release phase. Committed for all channels at once by an "execute" write.
Layer / splitA program plays up to 4 layers per note; each layer picks one split, a key/velocity window with its own sample and settings.
LFOLow-frequency oscillator for vibrato and tremolo.
ManateeSega's standard AICA sound driver (manatee.drv), shipped with the Katana SDK and used by many Dreamcast games.
MonitorAICA registers showing one selected channel's envelope and play position; the driver rotates through channels.
PortA player instance the game controls: 8 MIDI ports, 8 one-shot ports, 4 PCM stream ports.
PriorityPer port; decides which sounds may steal voices or PCM slots from which.
Ring bufferEither the DSP's delay memory or a stream's circular sample buffer, both in sound RAM.
sd librarySega's SH-4 sound library (sdMidiPlay, sdShotPlay, sdPstmPlay, …) that talks to Manatee.
SMPBMIDI program (tone) bank: programs → layers → splits.
SMSB / SMSDMIDI sequence bank / one sequence.
SOSBOne-shot bank: ready-made channel register images plus loop counts.
SFPB / SFOB / SFPWEffect program bank / effect output-set bank / effect work area (DSP ring buffer).
Sound RAMThe AICA's 2 MB memory, shared by the ARM, the voices, the DSP and the SH-4.
Status record32 bytes per port written by the driver every 4 ms for the game to read.
Timer AAn AICA sample-counting timer; Manatee's 1 ms / 4 ms heartbeat.
